## ✨ Fitur Utama

| Fitur | Deskripsi |
|-------|-----------|
| 👥 Manajemen Anggota | Pendaftaran, profil, arsip anggota |
| 💰 Kas & Iuran | Laporan keuangan & riwayat iuran |
| 📋 Absensi | Presensi kegiatan anggota |
| 🖼️ Galeri | Dokumentasi foto kegiatan |
| 📢 Pengumuman & Agenda | Informasi & jadwal kegiatan |
| 🔐 Multi-level Akses | Tamu / Anggota / Pengurus / Ketua / Super Admin |
| 🤖 AI Chatbot | Asisten komunitas berbasis Gemini AI |
| 🌐 Multi-bahasa | Indonesia / English / Jawa |
| 🌙 Dark Mode | Tema terang & gelap |
| 📱 PWA | Bisa diinstall di HP |

## 🛠️ Tech Stack

| Layer | Teknologi |
|-------|-----------|
| **Frontend** | React 19 + Vite 6 + TypeScript |
| **Styling** | Tailwind CSS v4 |
| **Database** | Google Sheets (via Apps Script) |
| **Storage** | Cloudflare R2 |
| **Backup** | Google Drive |
| **Hosting** | Vercel (Frontend + Serverless API) |
| **Auth** | PIN-based (tanpa akun) |
| **i18n** | i18next (id / en / jv) |
